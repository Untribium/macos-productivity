Open questions

, moves the keyboard here (back to the question you were on): j k pick a question, h l change it, Esc or , back.

macOS Reduce Motion is on. This prototype ignores it so you can judge the motion; the Motion switch sets it.

Sample data, relative to today. While the overlay is closed, Return stands in for caps+Return and c for quick capture. In capture, Return saves and closes, ⌃Return (caps+Return) saves and opens the list. Clipboard (fake) stands in for a copied link: capture offers it once as a pill at the start of the field, with the task it would make as the placeholder. Return on an empty field makes that task, typed text gets the link attached, Backspace on the empty field (or the pill's ×) drops it. "URL (unreadable)" is macOS only telling us there is a link. Tasks have no detail view: f or Return manages links (+ add or o adds, x removes). Done shows a group as soon as one of its tasks is done, with a "→ N open" line for the rest.

Groups: o on a task makes it a group of two (empty again: back to a plain task); O adds a task of its own. A heading stands for its tasks here. Text fields: Esc on an empty field leaves at once. With text, Esc once for normal mode in the field (h l, i a), Esc again saves and leaves.

Space marks tasks; actions then apply to the marks. >>, Tab, t+letter and == send tasks and you stay put (marks stay, so Tab Tab Tab keeps pushing). H J K L move them and you go along. Tab in the list (date pill): without marks, Tab shows where the task will go ("→ tomorrow") and it stays put; Tab Tab steps on, ⇧Tab back, the next key sends it (or, with the timer, 1 s after the last Tab), Esc cancels. With marks Tab sends at once. f opens a link: a menu below the task, Return or the link's letter (also gx).

Menus: One sheet puts due, time and links in one sheet below the task, a row each: Return opens all three (Links first), t s f only their own row (s f again: close; j k grow it to all three), j k pick the row, h l change the value directly. Every key means one thing in the whole sheet: t m w n - the date, 0–6 the time, o x add / remove a link, from any row. Esc or Return close and keep it (one u undoes the session; a new date sends the task on close). On Links, Return opens. x is a confirm: Return marks done, Esc cancels. x or s on several tasks (marks, a heading) asks one task at a time: Return each, ⇧Return all the rest, Esc stops.
